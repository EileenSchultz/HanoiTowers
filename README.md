# 🗼 Hanoi Towers (Ханойские башни)

Классическая головоломка "Ханойские башни" в 3D, реализованная на Unity. Переместите все диски с первого стержня на последний, соблюдая правило: нельзя класть большой диск на маленький.

## 📥 Быстрый старт (для игроков)

**Вам не нужен код!** Чтобы просто поиграть:

1. Перейдите в раздел **[Releases](https://github.com/EileenSchultz/HanoiTowers/releases)** этого репозитория
2. Скачайте архив `HanoiTowers_v1.0.zip`
3. Распакуйте его в любую папку
4. Запустите `HanoiTowers.exe`
5. Играйте! 🎮
   
---

## 🎯 Как играть

**Ручной режим**
1. Зажмите левую кнопку мыши на верхнем диске любого стержня
2. Перетащите диск на нужный стержень
3. Отпустите кнопку — диск упадёт на стержень
4. Цель: переместить все диски с левого стержня на правый
   
**Правила**
- ✅ Можно класть диск только на пустой стержень или на диск большего размера
- ❌ Нельзя класть большой диск на маленький
- 🏆 Победа: все диски на правом стержне

**Авто-решение**
1. Нажмите кнопку "Auto Solve"
2. Наблюдайте как алгоритм решает задачу
3. Можно менять скорость ползунком **Скорость**: 1x–5x во время решения
4. Нажмите Stop чтобы прервать и сбросить игру
   
**Настройки**
1. Ползунок "Количество дисков" — меняет сложность (3–10 дисков)
2. Ползунок "Скорость" — скорость авто-решения (1x–5x)
3. Кнопка "Reset" — сбросить игру к начальному состоянию

## 🎮 Возможности игры

- **3D визуализация** — разноцветные диски с отверстиями, деревянные стержни и база
- **Drag & Drop управление** — перетаскивайте диски мышкой
- **Проверка правил** — нельзя положить большой диск на маленький
- **Авто-решение** — алгоритм решает задачу за вас
- **Регулировка скорости** — от 1x до 5x прямо во время авто-решения
- **Настраиваемая сложность** — от 3 до 10 дисков
- **Динамическая камера** — автоматически подстраивается под количество дисков
- **Счётчик ходов** — показывает сколько ходов вы сделали
- **Панель победы** — красивое уведомление при завершении
- **Кнопка Stop** — можно прервать авто-решение в любой момент
- **Кнопка Reset** — сбросить игру в любое время

## 📂 Структура проекта

```text
HanoiTowers/
├── Assets/
│   ├── Scripts/
│   │   └── HanoiGameManager.cs  # Главный скрипт игры (вся логика)
│   ├── Scenes/
│   │   └── SampleScene.unity    # Основная сцена
│   └── Materials/               # Материалы для 3D объектов
├── ProjectSettings/             # Настройки проекта Unity
├── Packages/                    # Зависимости (URP, TextMeshPro)
├── .gitignore                   # Исключения для Git
└── README.md                    # Этот файл
```
---

### Ключевые компоненты кода

**`HanoiGameManager.cs`** — единственный скрипт проекта, содержит:
- Генерацию игрового поля (база, стержни, диски)
- Логику drag & drop
- Алгоритм авто-решения (рекурсивный)
- Управление UI (слайдеры, кнопки, текст)
- Динамическое управление камерой

## 🚀 Установка и запуск (для разработчиков)

### Требования
- **Unity Hub** 3.x+
- **Unity Editor** 6.6 (или новее)
- **Git** (опционально)

### Шаги установки

1. **Склонируйте репозиторий:**
   ```bash
   git clone https://github.com/EileenSchultz/HanoiTowers.git
2. Откройте проект в Unity:
   - Запустите Unity Hub
   - Нажмите Add → выберите папку HanoiTowers
   - Дождитесь импорта (Unity создаст папки Library, Temp автоматически)
3. Откройте сцену:
  - В окне Project перейдите в Assets/Scenes/
  - Дважды кликните на SampleScene
4. Запустите игру:
    Нажмите кнопку ▶ Play в верхней панели Unity
5. Сборка в .exe
В Unity: File → Build Profiles
  - Выберите платформу Windows
  - Убедитесь что сцена SampleScene добавлена в Scene List
  - Нажмите Build
  - Выберите папку для сохранения
  - Запустите полученный HanoiTowers.exe
Готовый билд также доступен в разделе Releases этого репозитория.
